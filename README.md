# e-plantShopping

## Overview
e-plantShopping is a React-based web application for purchasing a variety of houseplants. The application features a dynamic product listing separated into multiple categories, a shopping cart with real-time updates using Redux, and an interactive UI that allows users to add items, modify quantities, and remove them seamlessly.

## Features
- **Product Listing:** Browse through at least six unique houseplants across different categories.
- **Shopping Cart:** Add plants to the cart, update quantities, and see total costs computed in real-time.
- **Redux State Management:** Global state handles cart modifications reliably.
- **Responsive Navigation:** Access Product Listing and Cart pages easily via the top navbar.
